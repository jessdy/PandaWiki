## 二、kfs 安全报告.pdf（AppScan，25 项）

| 级别 | 报告项 | 处理 |
| --- | --- | --- |
| 高 | API 成批分配：`/share/v1/auth/login/user_password` 附加 `isadmin/issso/role` 仍 200 | 该接口已在当前版本移除（`handler/share/auth.go`），不再对外校验用户名密码 |
| 中 | 跨站请求伪造：伪造 Referer/Origin 调 `/share/pro/v1/consult/list` 成功 | `middleware/share_auth.go`：所有经 Share 鉴权的请求，只要带跨站 `Origin` 一律 403；写操作缺 Origin 时退回校验 `Referer`；同源判断兼容反代 `X-Forwarded-Host` |
| 低 | 过度许可 CORS（`Access-Control-Allow-Origin: *`） | 当前版本 `handler/share/cors.go` 只回显与请求 Host 一致的 Origin，不再输出 `*` |
| 低 | 缺少 CSP / X-Content-Type-Options；参考 Referrer-Policy 缺失 | 前台 `next.config.ts` 全站下发 CSP、`nosniff`、`Referrer-Policy`；Caddy 前台路由同时强制 `nosniff`、`Referrer-Policy`；后端 API 已有 `SecurityHeaders` 中间件 |
| 低 | 不必要的 HTTP 响应头（`X-Powered-By`、`X-Middleware-Rewrite`、`X-Current-Path`） | `poweredByHeader: false`；`x-current-path/x-current-search` 改为通过请求头传给服务端组件，不再下发浏览器；Caddy 前台路由删除 `X-Powered-By`、`X-Middleware-*`、`X-Current-*`、`X-Nextjs-*`、`Server` |
| 低 | 数据库错误模式 / 应用程序错误（`status=%00` 返回 `SQLSTATE 22021`） | 咨询列表 `status` 参数按枚举校验；统一错误响应 `NewResponseWithError` 识别数据库/网络/文件路径类错误原文，对外只返回“服务器内部错误 + trace_id”，详情仅写日志 |
| 低 | Cookie 缺 SameSite（`x-pw-session-id`、`_pw_auth_session`） | 两者均为 `SameSite=Lax` + `HttpOnly` + `Secure` |
| 低 | 持久 Cookie（`_pw_auth_session` 30 天、`x-pw-session-id` 1 年） | 两者均改为会话级 Cookie（关闭浏览器失效） |
| 信息 | 电子邮件地址模式（JS 中 Sentry DSN） | Sentry DSN 改为构建时环境变量 `NEXT_PUBLIC_SENTRY_DSN`，默认空，不再打进前端包 |
| 低 | ASP.NET 路径泄露 ×4 / 错误页路径泄露（`/noSuchFile.thtml`） | 误报：系统不是 ASP.NET，404 页面里只有 Next 静态资源的相对路径，无服务器物理路径；不再下发 `X-Powered-By`，降低指纹识别 |
| 信息 | 服务器路径模式 / JS Cookie 引用 ×3 | 误报：RSC 数据中的是前端路由路径；JS 只读写主题偏好等非敏感 Cookie，会话 Cookie 均为 HttpOnly |

## 仍属运维/产品决策（未改架构）

- API 进程明文 `Start`：依赖反代 TLS 终结（现网 nginx/caddy）
- 中间件/前端 alpine 镜像完整信创替换：需采购对应基础镜像

- 密级横幅：能力已有，默认关闭，按策略开启

## 部署注意

- 生产请勿设置 `COOKIE_SECURE=false`
- 管理端需同源访问 API（Cookie 才生效）；升级后请重新登录
- `.env` 必须配置 `S3_ACCESS_KEY`（原部署已有，沿用原值即可，MinIO 数据不受影响）
- Caddy 响应头调整在 API 启动同步 Caddy 配置时生效（重启 API 或保存任意知识库设置即可）
- 前台 CSP 允许外部图片/视频及 iframe 嵌入（挂件场景）；若页面出现资源被拦截，可在 `web/app/next.config.ts` 的 `contentSecurityPolicy` 中补充来源
